# KYC Service

Responsibilities:

- Customer identity status.
- KYC vendor integration boundary.
- Manual review workflow.
- Document metadata and retention policy hooks.
- User trading/withdrawal eligibility signal.

Initial states:

```text
NOT_STARTED
PENDING
UNDER_REVIEW
APPROVED
REJECTED
EXPIRED
SUSPENDED
```

No raw document storage design is accepted until privacy, encryption, retention, and vendor responsibilities are documented.
